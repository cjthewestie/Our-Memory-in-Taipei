# Harry Potter and the Philosopher's Stone (Book 1)

J.K. Rowling, 1997. US title: *Harry Potter and the Sorcerer's Stone*.

This folder is for your own copy of the book. The book is under copyright, so
it isn't in the repo. Put your copy here (for example `book.epub` or `book.pdf`).
Git ignores those files, so your copy stays on your machine and never gets
pushed.

Legal ways to get it:
- An ebook you bought (Pottermore Publishing, Kindle, Apple Books, Kobo)
- A library loan through Libby/OverDrive
- A print copy

Nothing in this folder is loaded by the page.
