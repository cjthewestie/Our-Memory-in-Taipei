# Demo kit: Our Memory in Taipei

What to paste into a pitch to a place operator (temple, museum, tourism office). Live page: https://cjthewestie.github.io/Our-Memory-in-Taipei/

| File | What it is |
|---|---|
| `pitch.md` | One-paragraph pitch (89 words) and a 3-line "what we could build for your place" list. Price is left as (unknown — needs CJ). |
| `01-opening-title.png` | 1440x900. The opening frame: the title "Our Memory in Taipei" in the fog before scrolling. |
| `02-ximending.png` | 1440x900, scroll 0.18 (1993). Ximending: the Red House, the girl running, the word "That feeling." |
| `03-dadaocheng.png` | 1440x900, scroll 0.45 (2009). Dadaocheng: Dihua Street at Lunar New Year, lanterns and stalls, "Spring Festival." |
| `04-taipei101-base.png` | 1440x900, scroll 0.78 (2023). Looking up at Taipei 101 from its base in Xinyi. |
| `05-closing-climb.png` | 1440x900, scroll 1.0. The end: the man on Taipei 101 and the closing line. |
| `06-phone-ximending.png` | Phone, 390x844 viewport at 2x pixel density (780x1688 file), scroll 0.18. Ximending on a phone. |

Screenshots were taken headless (Chromium headless shell, Metal WebGL; SwiftShader was too slow to render this scene) from the working copy at https://joy-shen123.github.io/Our-Memory-in-Taipei/, waiting 80 frames after each scroll.
