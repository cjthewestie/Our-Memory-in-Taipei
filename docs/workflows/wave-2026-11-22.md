# Wave 2026-11-22: about 50 agents finish the three districts and the square

CJ, 2026-11-22: 「那些弱點也一起修掉」, 「繼續用力加速改」, then 「開50個把它做完」.

Every builder owns its files. No two agents write the same file. A new piece lives in its own module `remake/lm/<district>-<piece>.js`, loaded by `remake/lm/loader.js` and run at the end of the page's build (after `LANDMARKS_<DISTRICT>(E)` and `PLACES.mount`). A module that replaces old geometry hides the old object at run time (found through `window.__places.entries` by item key, or by name or position), never by editing another agent's file. 西門町 lanes open extra walkable ground by pushing `{x0, x1, z0, z1}` into `window.LM_AREAS` (read by the clamp in `index.html`) and close their own ends with `PHOTOWALL.block`.

Status: `todo` → `taken` (workflow running) → `done` (reported) → `verified` (passed the adversarial check) → `committed`.
