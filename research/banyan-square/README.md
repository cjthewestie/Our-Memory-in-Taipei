# 榕樹廣場:真實的樣子,和怎麼把場景做好

2026-11-03。CJ:「燈籠先拆掉 做一個完整的榕樹廣場 /research 先做個研究真實的廣場還有怎麼把場景做好」。
這份是動手前的研究,`square.js` 照這裡做。來源都附在每段後面。

## 一、真實的榕樹廣場長什麼樣子

### 1. 樹不只是樹:「大樹公」和「伯公下」
- 台灣很多老榕樹被當成神,叫「大樹公」「樹仔公」。它常和土地公(福德正神)一起被祭拜,也被當成孩子的守護神。高雄縣一地就記錄到 136 處大樹公,大多是榕樹。
  ([Trees in Taiwanese Folklore](https://edizionicafoscari.unive.it/it/edizioni4/riviste/the-venice-journal-of-environmental-humanities/2022/2/trees-in-taiwanese-folklore/)、[Michael Turton 整理的大樹信仰](https://michaelturton.blogspot.com/2016/11/some-features-of-big-tree-worship-in.html?m=1))
- **神樹常用紅布或紅帶繞住樹幹**,這是一眼就認得出「這棵樹有人在拜」的記號。([同上](https://michaelturton.blogspot.com/2016/11/some-features-of-big-tree-worship-in.html?m=1))
- 客家話把土地公廟和它周邊統稱「伯公下」:遮雨棚、涼亭、**大榕樹下的廣場、石桌石椅**都算在內。居民在這裡奉茶、聊天、講古,自然成了聚落的活動中心。稍有年代的伯公下幾乎都有一棵大樹,樹被當成伯公本身,枯了會補種。
  ([教育部客家語辭典 · 伯公下](https://hakkadict.moe.edu.tw/static/resource/禮俗/109_024_伯公下.pdf))
- 最早的土地公廟很簡單,「兩塊石頭為壁,一塊為頂」,就蓋在樹下或路邊;後來才變成有屋頂、有燕尾脊的小廟。([CNA](https://www.cna.com.tw/news/aloc/201906060098.aspx)、[newtalk](https://newtalk.tw/news/view/2021-02-11/532502))
- 台北的例子:北投清天宮旁的老榕樹,當地叫「樹仔公」,市府立碑,「福澤庇蔭鄰里兩百餘年」;新北深坑老街街尾,土地公廟旁的老榕樹是遊客乘涼休息的地方。([ETtoday](https://www.ettoday.net/news/20260605/3178096.htm)、[NOWnews](https://www.nownews.com/news/3100496))

### 2. 樹下有誰、在做什麼
- 艋舺公園(萬華)的調查:白天的使用者過半是社區長者,七十歲以上最多;公園被形容成「白天是長者的交誼廳」。地下二樓以前是長者看電視、喝茶、**唱歌、跳舞**的地方。
  ([關鍵評論網](https://www.thenewslens.com/article/96836)、[公視](https://news.pts.org.tw/article/758679))
- 所以樹下該有的生活:**下象棋**、**泡老人茶**、**聊天**、坐在樹圍上乘涼搧扇子、角落的**卡拉OK**。

### 3. 榕樹本身
- 小葉榕(*Ficus microcarpa*):常綠大喬木,**樹冠圓而扁、比樹高還寬**。枝上垂下大量氣根,像簾子;一部分氣根落地後木質化,變成**支柱根**撐住往外長的樹冠;樹幹基部常有板根。
  ([NParks Flora & Fauna Web](https://www.nparks.gov.sg/florafaunaweb/flora/2/9/2913)、[HKU 氣根研究](https://hub.hku.hk/handle/10722/215014)、[Lucid · Ficus microcarpa](https://apps.lucidcentral.org/plants_se_nsw/text/entities/ficus_microcarpa.htm))
- 樹皮淺灰、平滑。之前做成深咖啡色是錯的。

### 4. 廣場的組成清單(從上面整理)
| 元素 | 為什麼要有 |
|---|---|
| 大榕樹,樹幹繞紅布 | 大樹公,整個廣場的中心 |
| 樹下的土地公廟(福德祠)、香爐、金爐 | 「伯公下」的核心;紅色、有燈,是天然的視覺焦點 |
| 樹圍座椅、石桌石椅 | 乘涼、下棋、泡茶 |
| 長者:下棋、泡茶、搧扇子 | 樹下真正的生活 |
| 小卡拉OK站 | CJ 指定;也真的是公園和廟口常見的 |
| 社區公布欄 | 每個里都有;**拿來放大家的記憶**,取代燈籠 |
| 攤車(烤香腸) | 廟口一定有 |
| 路燈、騎樓、機車、盆栽、鴿子 | 讓它像台北的一個角落,而不是一個舞台 |

## 二、怎麼把場景做好

### 1. 構圖:一個焦點,三層景深
- 焦點要先決定,而且要比周圍亮、位置突出;其他的線條和形狀要把視線帶過去。
  ([Game Developer · Composition in Level Design](https://gamedeveloper.com/design/composition-in-level-design)、[Creative Bloq](https://www.creativebloq.com/professional-development/artistic-tips-techniques/how-to-create-convincing-environment-art))
- 分前景、中景、背景,用對比、邊緣和空氣感拉開層次;風格化作品常把前景做成剪影。
  ([Creative Bloq · matte painting](https://www.creativebloq.com/art/digital-art/how-to-structure-a-matte-painting-to-create-a-cinematic-environment-game-concept-or-personal-illustration)、[80.lv · Forest Ruins](https://80.lv/articles/forest-ruins-searching-for-atmosphere-in-3d-spaces))
- 用明暗把焦點推出來:亮的東西放在暗的背景前,或暗的剪影放在亮的背景前。
- 物件大小要有變化、要互相遮擋,不要排成一列。([freegamesprites · depth tricks](https://freegamesprites.com/ar/news/pixel-art-scene-depth-composition-tricks))

**套到廣場**:進場那一眼,焦點是**樹下亮著紅光的土地公廟**,上面壓著**暗綠色的樹冠剪影,背後是黃昏的亮天空**。左右兩側的卡拉OK和攤車當前景框,騎樓和三座門是背景。

### 2. 風格化的樹:一叢一叢的葉片卡,而不是幾顆大球
- 業界做法:很多小的「葉片卡」(貼了一叢葉子、透明背景的平面),排成一團一團,再把法線改成**從樹冠中心往外的球狀法線**。這樣整棵樹打光像一朵蓬鬆的雲,但邊緣還是碎葉的輪廓。
  ([Unreal 論壇 · spherical normals](https://forums.unrealengine.com/t/spherical-normals-for-trees-blender/98732)、[Habrador · stylized trees](https://blog.habrador.com/2018/05/how-to-make-stylized-witness-trees-in.html)、[SIGGRAPH · aggregate normals](https://history.siggraph.org/?p=142493))
- 球狀法線的缺點是葉叢之間的層次會被抹平,改成「每一叢有自己的中心」會比較好。([NextPCG 說明](https://devcopilot.notion.site/NextPCG-SpeedTree-Smooth-Normal-Baker-c633d36bddc7423d8dc2a0c1e5e60086))
- 透明裁切(alphaTest)讓葉子邊緣碎碎的;再加一點隨時間的搖晃,樹就活了。
  ([Godot Shaders · Stylized Fluffy Tree Leaves](https://godotshaders.com/shader/stylized-fluffy-tree-leaves/)、[polygon-wind](https://www.Github.com/RenanBomtempo/polygon-wind))

**套到我們的 three.js r149**:
- 一個 `InstancedMesh`,放約 800 張葉片卡,只要 1 次繪製。
- 葉片圖在 canvas 上畫。
- 在 `onBeforeCompile` 裡把法線換成「從所屬葉叢中心往外」的方向,並加上風吹搖晃。
- 影子用 `customDepthMaterial` 加 alphaTest,樹下才會有斑駁的碎影,而不是一整塊黑。
- 樹冠裡面放幾團深綠色的實心塊,補洞。

### 3. 光:黃昏、可信的光源
- 拆掉燈籠以後,黃昏的亮點改由**真的會亮的東西**負責:土地公廟裡的神明燈、路燈、店面、卡拉OK的電視。
- 發光物不做色調映射(`toneMapped: false`),場景整體曝光在黃昏時壓低一點,亮的東西才跳得出來(之前已做的 `WALK.dusk`)。
- 不加真正的點光源:一加,整條街每個材質都要重新編譯,會卡頓。

### 4. 效能預算
重複的小東西一律 `InstancedMesh`:窗、鐵窗、冷氣、柱、機車、盆栽、氣根、葉片卡。整個廣場維持幾十次繪製。

## 三、做法(`square.js`)
1. 拆掉所有燈籠:樹上的、拉到騎樓的燈串、大稻埕門上的。
2. 榕樹重做:淺灰樹皮、板根、多幹合生、支柱根、垂簾氣根、葉片卡樹冠、樹幹繞紅布。
3. 樹的南面蓋一間土地公廟(燕尾脊、紅柱、「福德祠」匾、神明燈、香爐),旁邊一座金爐。
4. 樹下:象棋桌、泡茶桌(茶盤、茶壺、茶杯),長者在下棋、泡茶、搧扇子。
5. **記憶公布欄**:大家的記憶貼成一張張紙條;走近按 E,打開「最新記憶」清單。
6. 烤香腸攤車、台北式路燈、騎樓前的盆栽、地上的鴿子。
7. 卡拉OK站保留。
